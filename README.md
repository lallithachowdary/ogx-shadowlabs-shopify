
# OGX Studio — Shadow Labs Shopify Sections

This project recreates three Shadow Labs website sections for the OGX Studio Track 2 assessment.

## Sections

1. `sections/transformation.liquid` — Customer transformation stories and testimonials.
2. `sections/comparasion.liquid` — Shadow Labs feature comparison table.
3. `sections/value-stacks.liquid` — Product bundles, pricing, discounts, and CTA buttons.

## Technologies

- Shopify Liquid
- HTML
- CSS
- JavaScript

## Usage

Copy the three Liquid section files into the `sections` directory of a Shopify theme. Add the sections through the Shopify Theme Editor and configure their settings.

The sections should be tested in a Shopify development theme before production use.
